구독 플랜 상속 구조와 다형성 시각화

SubscriptionADT → Subscription → Free/Basic/Standard/Premium 구조를 웹에서 시각화했습니다. 각 플랜을 클릭하면 오버라이딩된 메서드가 실행됩니다.

상속 구조

ADT → Base Class → Instances

실행 결과

클릭하면 오버라이딩 메서드 결과가 출력됩니다.

왼쪽의 클래스 노드나 구독 플랜 카드를 클릭해보세요.

다형성 포인트

같은 yearlySubscription()을 호출해도 Free/Basic은 “연간 구독 미제공”, Standard/Premium은 “20% 할인 연간 구독”을 출력합니다.
